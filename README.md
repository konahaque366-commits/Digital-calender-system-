
📅 Digital Calendar System
A simple, interactive, and user-friendly Digital Calendar System developed using Java Swing. This application allows users to view and navigate through different months and years using an easy-to-use graphical interface.

📌 Project Overview
The Digital Calendar System is a Java-based desktop application designed to provide a digital representation of a traditional calendar.
The application displays the days of the week and dates for the selected month and year. Users can navigate between previous and next months and view calendars for different years.
This project was developed as an academic project to gain practical experience in Java programming, Object-Oriented Programming, Java Swing, GUI design, and event handling.

🎯 Objectives
The main objectives of this project are:
To develop a functional digital calendar using Java.
To create an interactive GUI using Java Swing.
To implement event handling and user interaction.
To understand date and calendar operations.

⚙️ How It Works
When the application starts, it displays the calendar for the selected or current month and year.
The system calculates the correct starting day and number of days for each month and then displays the dates in the appropriate positions.
Users can navigate through the calendar using the available controls.
Main Operations
Previous Month:
Moves the calendar to the previous month.
Next Month:
Moves the calendar to the next month.
Year Navigation:
Allows users to view the calendar for different years.
Date Calculation:
Automatically calculates and displays the correct dates according to the selected month and year.
